    hikari, a modern theme for the mpv video player¶

    Built on uosc, made for watching series and anime on mpv.

    Install See it on GitHub

    hikari is a skin for mpv in the sense people usually mean: a ready-made, good-looking setup, not a new on-screen controller written from scratch. It installs the official uosc and thumbfast, configures them, and adds a few small Lua scripts of its own on top. Everything it changes in your config folder is backed up first, and it can be uninstalled. A one-minute showreel is on the GitHub page.

    Quick install¶

    Open PowerShell (no administrator rights needed) and run:

    irm https://github.com/SCEPTICG/hikari-mpv/releases/latest/download/hikari.ps1 | iex

    It finds mpv, mpv.net and AnimeJaNai. Details: Install on Windows.

    Open Terminal (no sudo) and run:

    curl -fsSL https://github.com/SCEPTICG/hikari-mpv/releases/latest/download/hikari.sh | bash

    Details: Install on macOS and Linux.

    A menu opens: choose Install or update and the player. Run the same line again to update or to uninstall.

    What you get¶

    • 14 colour palettes

      Catppuccin, Tokyo Night, Dracula, Nord, Gruvbox, Rosé Pine, Kanagawa, One Dark, Everforest, Solarized and hikari's own, SCEPTIC. Alt+p, applied at once.

      Palettes

    • Skip openings and endings

      A Saltar opening › button while a chapter looks like an opening, intro or ending. One click or Alt+s.

      Skip openings and endings

    • Timeline thumbnails

      Previews on hover through thumbfast, on network streams too, with the chapter name.

      Thumbnails

    • Subtitle styles

      Caja oscura, Borde grueso and Amarillo clásico, plus size and height. Alt+t.

      Subtitle styles

    • Automatic Anime4K

      Anime4K's modes, and Automático, which picks the mode from each video's resolution, with a quality for your graphics card.

      Anime4K upscaling

    • A controls bar for single episodes

      A filled timeline with the opening and ending marked, readable stream titles, a speed menu and an update notice.

      Keys and configuration

    The on-screen labels are in Spanish for now (Saltar opening, Subtítulos, Velocidad, Paletas, Escalado). The installer speaks English or Spanish, following your system.

    hikari and other mpv themes¶

    • uosc is the on-screen controller hikari is built on. If you already use uosc, hikari is a configuration plus a few scripts on top of it, not a fork: your uosc stays the official one.
    • ModernX and ModernZ are other replacements for mpv's built-in OSC. They clash with uosc, so the installer sets them aside (nothing is deleted) and puts them back on uninstall.
    • mpv.net and AnimeJaNai are supported on Windows: hikari installs into the config folder each of them reads.
